# BD Tech Tailoring - Admin Dashboard & CMS UI

An enterprise administration dashboard designed for custom tailoring platforms to manage fulfillment logistics, driver assignments, and homepage promotional content.

##  Features & Modules

###  Delivery & Logistics Management
* **Real-time Overview Metrics:** Summary cards tracking pending assignments, orders in transit, daily completions, and delivery exceptions.
* **Interactive Delivery Queue:** Order list categorized by status flags (`Pending`, `In Transit`).
* **Order Status Timeline:** Visual step-by-step lifecycle tracker (`Stitching Completed` → `Package Checked` → `Pending Assignment` → `Out for Delivery`).
* **Driver Assignment System:** Interactive dropdown components allowing admins to pair orders with specific logistics partners or drivers.

###  Content Management System (CMS)
* **Homepage Banner Manager:** Toggle active banner visibility and drag-and-drop file upload zone for new promotional graphics.
* **Promotional Offers Table:** Data table to manage promo codes, validity dates, status badges (`Active` / `Inactive`), and quick actions.

##  Tech & Design Stack

* **Design Tool:** Figma (Auto Layout, Component Variants, Dynamic Dropdowns)
* **Suggested Tech Stack:** React / Next.js, Tailwind CSS, TypeScript, Shadcn UI / Radix UI
